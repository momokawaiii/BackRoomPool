本项目搭建一套模块化、可扩展的现代 OpenGL 实时渲染管线，完整实现水体物理渲染、PBR 物理材质、IBL 基于图像光照、实时阴影映射四大核心模块。严格遵循物理光照规则与能量守恒，采用多 Pass 分层渲染架构，兼顾渲染画质、物理一致性与实时性能。
多 Pass 反射 / 折射管线
基于 FBO 离屏渲染，分别生成水面反射、折射纹理，结合视角因子做物理混合，还原真实水面透视效果
菲涅尔 Fresnel 效应
采用 Schlick 近似公式，根据视线夹角动态调控反射、折射权重，符合光学物理规律
DUDV 动态水面波动
利用 DUDV 扰动贴图 + 时间动画偏移，模拟水面波纹、流动扰动与法线起伏
基于深度的水体吸收
引入 Beer–Lambert 比尔 - 朗伯定律，模拟光线在水体中的衰减散射，实现近浅远深的自然水下变暗效果
物理基础渲染 PBR
Cook–Torrance BRDF(GGX)
标准金属度 / 粗糙度工作流，严格遵循能量守恒，实现物理正确的漫反射 + 高光反射计算
法线贴图与 TBN 切线空间
构建完整 TBN 矩阵，适配模型非均匀缩放，保证法线扰动、细节映射渲染无畸变
统一多光源光照模型
原生支持方向光、点光、聚光灯，所有光源统一接入 PBR 渲染逻辑，适配复杂场景多光源照明
IBL 基于图像光照
HDR 全景图转立方体贴图
GPU 实时将经纬度格式 HDR 环境贴图转换为标准 Cubemap，作为全局环境光照源
全套 IBL 预计算管线
离线 / 实时预计算 辐照度贴图、预过滤高光贴图、BRDF LUT，完整支持漫反射环境光与高光环境光
直接光照 + 间接光照协同
IBL 负责全局低频环境能量分布，直接光源补充局部高频光影细节，画面层次更具物理真实感
实时阴影映射 Shadow Mapping
方向光标准阴影贴图
基于正交投影构建深度贴图，实现场景高精度实时阴影绘制
PCF 百分比滤波软阴影
多重采样加权滤波，平滑阴影锯齿边缘，替代生硬硬阴影，提升画面质感
自适应光照视锥体
根据场景 AABB 包围盒自动适配灯光投影范围，最大化阴影贴图利用率与阴影分辨率，减少浪费
